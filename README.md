# Curso de Análisis de Algoritmos

Repositorio utilizado durante el curso de Análisis de Algoritmos.

## Descripción

Este repositorio contiene los laboratorios, ejercicios de clase y scripts utilizados durante el semestre.

## Estructura del repositorio

- `laboratorios/`: contiene los cinco laboratorios evaluativos del curso.
- `ejercicios-clase/`: contiene ejercicios realizados durante las sesiones prácticas.
- `benchmarks/`: contiene scripts utilizados para medir y comparar tiempos de ejecución.

## Ejecución

Los ejercicios desarrollados en Python pueden ejecutarse desde la terminal:

```bash
python nombre_archivo.py
```
